# 机器学习课程作业仓库

机器学习课程(2023级)的作业代码、期末项目与论文归档。

## 仓库结构

| 目录 / 文件 | 说明 |
|---|---|
| `homework_week_*.py` | 各周作业代码(第 1、3~7、9~13 周) |
| `final_exam.py`, `torch_models/final_exam_2.py` | 期末项目代码 |
| `eval_backbone.py`, `eval_local.py`, `inference_test.py`, `preprocess_crops.py` | 期末项目:特征提取、推理与预处理 |
| `2023192004 张铭 mapping.csv` | 测试图片文件名 → 类别标签映射 |
| `2023192004 张铭 期末论文.pdf`, `期末论文2.doc` | 期末论文(含修订版) |
| `test.tex` | 期末论文 LaTeX 源码 |
| `*.png` | 训练曲线、聚类可视化等结果图 |

## 说明

期末项目内容:爬取社交平台猫咪图片 → 预训练模型提取特征/微调 →
聚类分析 → 测试集分类预测(提交格式见 `mapping.csv`)。
